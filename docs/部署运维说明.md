# 智慧办公平台 部署运维说明文档

> 适用系统：宏友软件 OA 系统（Vue3 + Express + MySQL）
> 文档版本：v1.0
> 更新日期：2026-08-13
> 本文档说明系统的 Nginx 部署、性能/安全优化、开机自启配置及日常运维命令。

---

## 一、系统架构

```
浏览器/客户端
     │
     ▼
 Nginx 反向代理 (端口 8080，生产模式)
     │  ├── /            → 前端静态文件 (dist/)
     │  ├── /api/        → 后端 API (127.0.0.1:3005)
     │  ├── /uploads/    → 上传文件 (127.0.0.1:3005)
     │  └── /socket.io/  → WebSocket 长连接 (127.0.0.1:3005)
     │
     ├── 开发服务器 (端口 3003，可选)
     │
     └── 后端服务 (端口 3005，pm2 管理) ──► MySQL
```

| 服务 | 端口 | 说明 | 管理方式 |
|------|------|------|---------|
| 前端（生产） | 8080 | Nginx 托管 dist 构建产物 | `nginx.exe` |
| 前端（开发） | 3003 | Vite dev server（`npm run dev`） | 手动 / 自启脚本 |
| 后端 API | 3005 | Express + Socket.IO | pm2 |

## 二、Nginx 部署

### 目录结构

```
nginx-1.22.1/
├── nginx.exe              # 可执行程序
└── conf/
    ├── nginx.conf         # 主配置
    ├── qygl.conf          # OA 站点配置（include 引入）
    └── security-headers.conf  # 公共安全响应头
```

### 配置文件说明

| 文件 | 作用 |
|------|------|
| `nginx.conf` | 主配置：worker 调优、事件模型、gzip、日志格式、限流 zone 定义 |
| `qygl.conf` | 站点配置：监听 8080、静态文件、反向代理、WebSocket、安全头、限流应用 |
| `security-headers.conf` | 安全响应头（CSP、X-Frame-Options 等），多处 include 复用 |

### 启动 / 停止 / 重载

在 `nginx-1.22.1` 目录下执行：

```bat
:: 启动
start nginx.exe

:: 停止
nginx.exe -s stop

:: 平滑重载（修改配置后执行）
nginx.exe -s reload

:: 校验配置语法
nginx.exe -t
```

### 常用端口说明

- **80 端口**被系统 Apache（`httpd.exe`）占用，故 OA 使用 **8080** 端口
- 若要使用 80 端口（免端口号访问），需先停用 Apache 服务

## 三、Nginx 优化项清单

### 3.1 性能优化（`nginx.conf`）

| 优化项 | 配置 |
|--------|------|
| worker 进程数 | `worker_processes 4`（按 CPU 核数） |
| 文件描述符上限 | `worker_rlimit_nofile 65535` |
| 传输优化 | `sendfile on`、`tcp_nopush on`、`tcp_nodelay on` |
| 文件缓存 | `open_file_cache`（提升静态文件读取） |
| 长连接 | `keepalive_requests 500` |
| gzip 压缩 | 文本/JSON/JS/CSS 等启用 gzip |

### 3.2 缓存策略（`qygl.conf`）

| 资源 | 策略 |
|------|------|
| `index.html` | **不缓存**（no-cache，前端发版立即生效） |
| `/assets/*`（带 hash） | 长缓存 7 天 + immutable |
| `/uploads/*` | 缓存 1 天 |
| API 动态接口 | 不缓存（由后端处理） |

### 3.3 安全加固（`qygl.conf` + `security-headers.conf`）

| 安全项 | 说明 |
|--------|------|
| 安全响应头 | CSP、X-Frame-Options、X-Content-Type-Options、X-XSS-Protection、Referrer-Policy、Permissions-Policy |
| 敏感路径屏蔽 | `.env`、`.git`、`*.sql`、`*.log`、`*.bak`、`node_modules` 等返回 403 |
| 登录限流 | `/api/auth/login` 每 IP 每分钟 5 次，超限返回 429 |
| 通用 API 限流 | `/api/` 每 IP 每 5 秒 30 次 |
| 连接数限制 | 单 IP 最多 100 并发连接 |
| 隐藏版本号 | `server_tokens off` |
| 上传目录 | `autoindex off`（禁止目录列表） |

### 3.4 HTTP/2 说明

- 当前**未启用**明文 HTTP/2 (h2c)，因与部分客户端（.NET HttpClient、部分 curl）存在协议冲突
- **启用 HTTPS 后**可开启 HTTP/2：`listen 443 ssl http2;`，性能更佳

## 四、开机自启

### 配置方式

通过 **Windows 计划任务** `QYGL_AutoStart`（用户登录时触发）运行 `start-system.bat`，一次拉起三个服务。

### 自启脚本（项目根目录 `start-system.bat`）

```bat
启动后端      → pm2 start ecosystem.config.cjs   (端口 3005)
启动前端Nginx → nginx.exe                        (端口 8080，生产)
启动 dev server → npm run dev                   (端口 3003，开发)
```

脚本**幂等**：检测到服务已在运行则跳过，不会重复启动。
执行日志写入 `logs/startup.log`。

### 管理计划任务

```bat
:: 查看任务
schtasks /Query /TN "QYGL_AutoStart" /FO LIST

:: 手动运行
schtasks /Run /TN "QYGL_AutoStart"

:: 删除任务
schtasks /Delete /TN "QYGL_AutoStart" /F
```

## 五、后端服务（pm2）

### 常用命令

```bat
:: 查看进程
pm2 list

:: 重启后端
pm2 restart qygl-backend

:: 查看日志
pm2 logs qygl-backend

:: 保存当前进程列表
pm2 save
```

> 注意：Windows 上 pm2 不支持 `pm2 startup`（Linux 专用），开机自启由计划任务实现。

## 七、常见问题排查

### 7.1 访问 8080 页面 502 / 504

表示 Nginx 无法连接后端，检查：
1. 后端是否在运行：`pm2 list`，或访问 `http://localhost:3005/api/health`
2. 后端 3005 端口是否监听：`netstat -ano | findstr ":3005"`

### 7.2 登录接口返回 429

触发登录限流（每 IP 每分钟 5 次），等待约 1 分钟恢复。这是正常防护行为。

### 7.3 修改 Nginx 配置后不生效

执行 `nginx.exe -t` 校验语法，确认无误后 `nginx.exe -s reload`。

### 7.4 80 端口被占用

系统 Apache（`httpd.exe`）占用 80 端口。如需使用 80：
- 停用 Apache 服务，或将 OA 站点端口改为 80

### 7.5 查看 Nginx 日志

```bat
:: 访问日志（含请求/上游耗时）
nginx-1.22.1\logs\qygl-access.log

:: 错误日志
nginx-1.22.1\logs\qygl-error.log

:: 自启脚本日志
logs\startup.log
```
