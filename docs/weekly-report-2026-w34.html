Jenkinsfile 仍为高频变更区

本周 9 次修改 Jenkinsfile，CI 流水线稳定性仍需观察。建议下一次部署后验证 cron 定时构建不再无提交全量重跑。

useMenuPermission.ts 为未跟踪文件

该权限模块此前未 commit/push，导致部署机拿不到。已在 538fbc8 中纳入并推送，但需确认部署机已生效。

沙箱构建限制

本机沙箱 safe-delete 拦截目录级 rename/delete，vite build 须走 dist_new 中转方案。部署机无此限制，但开发机构建需留意。

pm2 进程常驻验证

v1.2.13/14 将 nginx + dev server 改为 pm2 托管。需在 Jenkins 构建结束后确认 3003/8080/3005 端口持续监听，防止构建子进程清理导致服务中断。

建议启用 PR 工作流

当前 0 PR / 0 Issue，所有变更直接 push main。对于涉及认证、权限等高风险改动，建议引入 PR review 机制降低风险。
