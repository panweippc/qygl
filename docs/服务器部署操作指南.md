# 智慧办公平台 服务器部署操作指南

> 目标服务器：`192.168.2.142`（Windows）
> 数据库：服务器已有 `qyglfb` 库（无需迁移数据）
> 文档版本：v1.0
> 更新日期：2026-08-14

本文档面向在服务器 `192.168.2.142`（Windows）上部署本系统的运维人员，从拉取代码到成功访问给出完整操作步骤。

---

## 一、部署前检查（前置条件）

在服务器上确认以下环境已就绪：

| 组件 | 要求 | 验证命令（PowerShell） |
|------|------|------------------------|
| Node.js | v18 及以上（建议 v20） | `node -v` |
| MySQL | 已有 `qyglfb` 库 | 用 Navicat/命令行确认 |
| git | 用于拉取代码 | `git --version` |
| Nginx | 1.22+（推荐项目自带） | `nginx -v` |

> 若服务器 Node.js 版本过低，安装 Node v20 LTS。
> 若服务器无 Nginx，可将本项目自带的 `nginx-1.22.1` 目录一并复制到服务器。

---

## 二、拉取最新代码

在服务器上选择代码存放目录（如 `E:\qy`），执行：

```bash
cd E:\
git clone <你的仓库地址> qy
cd qy
git pull origin main
```

> 若之前已 clone 过，只需 `git pull origin main` 拉取最新。

---

## 三、创建环境配置 `.env` ⚠️（关键步骤）

**`.env` 含数据库密码，不会随 git 提交**，拉取代码后需手动创建。

```bash
# 复制模板
copy .env.example .env
```

然后用记事本打开 `.env`，填写服务器实际配置：

```ini
# 数据库连接（服务器本机 MySQL）
DB_HOST=localhost
DB_PORT=3306
DB_USER=HY            # 服务器上的数据库用户名
DB_PASSWORD=HYruanjian01   # 服务器上的数据库密码
DB_NAME=qyglfb

# CORS 白名单（生产端口 8080）
CORS_ORIGINS=http://localhost:3003,http://127.0.0.1:3003,http://localhost:8080,http://127.0.0.1:8080,http://192.168.2.142:8080
```

> ⚠️ **DB_USER / DB_PASSWORD 必须与服务器上 MySQL 实际账号一致**。
> 如果服务器数据库账号与开发机不同（如用户 `qygl`、不同密码），请按实际情况修改。
> 当前开发机 `.env` 里是 `HY / HYruanjian01`，需确认服务器上的账号密码是否相同。

## 四、安装依赖

在项目根目录执行：

```bash
cd E:\qy
npm install
```

> 若网络受限，可使用国内镜像：`npm config set registry https://registry.npmmirror.com` 后重试。

---

## 五、构建前端

```bash
npm run build
```

构建产物生成到 `dist/` 目录，供 Nginx 使用。

---

## 六、启动后端（pm2）

### 6.1 安装 pm2（若未安装）

```bash
npm install -g pm2
```

### 6.2 启动后端

```bash
# 首次启动
pm2 start ecosystem.config.cjs

# 保存进程（开机恢复用）
pm2 save
```

### 6.3 验证后端

```bash
# 访问健康检查（应返回 ok）
http://localhost:3005/api/health
```

---

## 七、配置 Nginx

将项目自带的 `nginx-1.22.1` 放到服务器（如 `E:\qy\nginx-1.22.1`），配置文件已就绪（`conf/nginx.conf` + `conf/qygl.conf`）。

**⚠️ 必须修改 `qygl.conf` 中的前端静态目录路径**，指向服务器上的实际路径：

文件：`E:\qy\nginx-1.22.1\conf\qygl.conf`

```nginx
# 把这行改为服务器上的实际 dist 路径
root  E:\qy\dist;
```

### 启动 Nginx

在 `nginx-1.22.1` 目录下：

```bat
:: 校验配置
nginx.exe -t

:: 启动
start nginx.exe

:: 重载配置（修改后）
nginx.exe -s reload
```

> ⚠️ **80 端口占用**：若服务器 80 端口被其他程序（如 Apache）占用，需改用 8080（配置已是 8080，无需改）或停用占用程序。

## 九、开机自启（可选）

参照 `start-system.bat`（项目根目录），通过 Windows 计划任务注册：

```bat
schtasks /Create /TN "QYGL_AutoStart" /TR "E:\qy\start-system.bat" /SC ONLOGON /RL LIMITED /F
```

> 需确保 `start-system.bat` 中的路径改为服务器实际路径。

---

## 十、常见问题排查

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 页面 502 | 后端未启动 | `pm2 list`，`pm2 start ecosystem.config.cjs` |
| 登录报 CORS | 白名单未含 `:8080` | 检查 `.env` 的 `CORS_ORIGINS` |
| 数据库连接失败 | `.env` 账号/密码不对 | 核对 DB_USER/DB_PASSWORD |
| 前端空白 | dist 路径不对 | 检查 `qygl.conf` 的 root |
| 端口被占 | 80 被 Apache 占用 | 使用 8080 |
